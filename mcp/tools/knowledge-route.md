# Tool: knowledge_route

## Purpose

Return the authoritative plane, read tools, write boundary, and epistemic status
for a known information class before retrieval.

## Input

- `information_type`: `persona_contract`, `standing_reference`,
  `research_source`, `approved_observation`, `episodic_memory`,
  `ship_definition_or_status`, `story_continuity`, or `campaign_state`

## Authority

Read-only routing metadata. It does not search, move, persist, or merge content.
