# Location Preset References

Drop reference images for recurring environments here. Keep originals rather
than overwriting them; use descriptive names such as:

- `home_living_room_01.jpg`
- `bedroom_evening_01.jpg`
- `hollow_ribbon_01.png`
- `silent_drift_exterior_01.webp`

Related angles, lighting variants, and detail shots may share the same base name
with an incrementing suffix. These files are visual references only; their
presence does not automatically make details canon or send them to an external
image, voice, or avatar provider.

Each catalog entry should carry a stable `location_id` resolving into the
repo-root `locations/` pack. Ship interiors belong under `../ship/` and resolve
to canonical facts in the repo-root `ship/` pack.
