# Ship Systems Overview

Narrative reference for each system. Live status values belong in
`ship/current_status.json`, not here.

- **Quantum Drive**: Primary FTL system and the blocker to leaving Earth.
  Currently unstable; entanglement coils need recalibration and partial
  replacement, and the phase regulator is a critical outstanding part.
- **Power Core**: Functional but running below optimal. Requires careful load
  management.
- **Stealth / Camouflage**: Modular. Optical and sensor-dampening layers are
  operational with manual setup, and active systems are power-hungry.
- **Holographic Disguise Emitter**: Supports Lyra's human presentation.
  Needs periodic recharging.
- **Life Support**: Fully functional for two. Atmosphere, temperature, and
  water recycling are solid.
- **Navigation Suite**: High-end Vossari navigator-grade systems. Intact.
- **Food Synthesizer**: Basic unit, currently broken.
- **Hull & Structural**: Minor entry damage; mostly cosmetic or non-critical.
  A bio-signature lock controls access.
